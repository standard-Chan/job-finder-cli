# 실행 메모

## Windows와 WSL node_modules 주의

이 프로젝트는 SQLite 라이브러리로 `better-sqlite3`를 사용한다.
`better-sqlite3`는 native module이라 설치한 OS에 맞는 바이너리를 `node_modules`에 만든다.

따라서 같은 프로젝트 폴더를 Windows와 WSL에서 번갈아 쓰는 경우 `node_modules`를 공유하면 안 된다.

Windows에서 실행할 때 다음 오류가 나면 Linux/WSL용 바이너리가 설치된 상태다.

```text
better_sqlite3.node is not a valid Win32 application
```

Windows 터미널에서 다시 설치한다.

```bat
rmdir /s /q node_modules
npm install
npm start
```

WSL에서 실행할 때 Windows용 바이너리가 설치되어 있으면 반대로 다시 설치한다.

```bash
rm -rf node_modules
npm install
npm start
```

실행 환경 하나를 정해서 `npm install`과 `npm start`를 같은 환경에서 실행하는 것이 가장 안전하다.
